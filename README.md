# 👋 Hi, I'm Flyx

I work in IT infrastructure at a FinTech company, keeping things running (and locked down) for ~1,500 users across 5 states. I've got a B.S. in Cybersecurity and an A.A.S. in Cloud Engineering Technology, and when I'm off the clock I'm usually in my homelab building something I didn't strictly need but definitely wanted.

## 💼 Day Job

- Infrastructure and operations for ~1,500 users at sites across 5 US states
- Identity and endpoint management with Entra ID, Active Directory, and Intune
- Security tooling with Splunk and Rapid7
- Cloud in Azure and AWS, with Terraform for infrastructure as code
- Automating the boring stuff with PowerShell and Python

## 🏠 Homelab & Side Projects

- **[Vault Sidekick](https://community.obsidian.md/plugins/vault-sidekick)** ([repo](https://github.com/FlyxHub/obsidian-vault-sidekick)): a Claude chat sidebar for Obsidian that runs on your local Claude Code login. It can read, search, and edit your notes, and asks before changing anything. I use it to draft knowledge base articles.
- **[Confluence Integration Plus](https://community.obsidian.md/plugins/confluence-integration-plus)** ([repo](https://github.com/FlyxHub/obsidian-integration-plus)): two-way sync between Obsidian and Confluence Cloud, including images and attachments. It's how those articles get published.
- **Discord bots**: all self-hosted in my homelab, running in Docker Compose on Ubuntu LXCs.
